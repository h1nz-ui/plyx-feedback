### 🐛 Found a Complex File That Breaks?
PLYX was built from scratch after two earlier prototypes failed on complex layouts. If you run into a tricky file that doesn't convert properly:
1. Go to the **[Issues](../../issues)** tab above.
2. Click **New issue** and tell me what file format/type broke (and attach a sample if you can!).
